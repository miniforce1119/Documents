## 💡 문제 해결

### 파일이 다운로드되지 않는 경우

**Option 1: wget 사용**
```bash
wget https://github.com/miniforce1119/Documents/raw/main/agent-builder-automation/releases/docs-automation-v1.0.tar.gz
```

**Option 2: curl 사용**
```bash
curl -L -o docs-automation-v1.0.tar.gz https://github.com/miniforce1119/Documents/raw/main/agent-builder-automation/releases/docs-automation-v1.0.tar.gz
```

**Option 3: Git 클론**
```bash
git clone https://github.com/miniforce1119/Documents.git
cd Documents/agent-builder-automation/
# 압축 파일이 releases/ 폴더에 있음
```

**Option 4: 브라우저 직접 다운로드**
1. https://github.com/miniforce1119/Documents 방문
2. `agent-builder-automation/releases/` 폴더로 이동
3. `docs-automation-v1.0.tar.gz` 클릭
4. "Download" 버튼 클릭
