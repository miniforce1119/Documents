# 프로젝트 3: MKDocs 문서 사이트 만들기

> **유형**: 바이브 코딩 | **난이도**: :material-star::material-star: | **준비물**: Python, Git, VS Code, GitHub 계정

---

## 목표

AI에게 물어보고, 복사하고, 붙여넣는 것만으로 **나만의 문서 웹사이트**를 만들어 인터넷에 배포합니다.

!!! tip "바이브 코딩이란?"
    코드를 직접 작성하지 않고, AI에게 프롬프트로 요청해서 만드는 개발 방식입니다.
    복사 → 붙여넣기 → 실행 → 수정 요청의 반복입니다.

---

## 상세 가이드

이 프로젝트는 이미 상세한 단계별 가이드가 준비되어 있습니다.

:material-arrow-right: **[바이브 코딩 MKDocs 가이드](https://miniforce1119.github.io/Documents/guides/vibe-coding-mkdocs-guide/)** 를 따라 진행해주세요.

---

## 가이드 요약

### Part 0-1: 환경 설정

- Python, Git, VS Code 설치
- GitHub 계정 생성

### Part 1-3: 프로젝트 생성

- AI에게 MKDocs 프로젝트 구조를 요청
- `mkdocs.yml` 설정 파일 생성
- 마크다운 문서 작성

### Part 3: 로컬에서 미리보기

```bash
mkdocs serve
```

브라우저에서 `http://localhost:8000` 으로 내 사이트를 미리 확인합니다.

### Part 4-5: GitHub에 배포

- GitHub 저장소 생성
- 코드 업로드
- GitHub Actions로 자동 배포 설정

### Part 6: 문서 추가 및 업데이트

- 새 문서를 추가하고 push하면 자동으로 사이트에 반영

- 누구나 접속할 수 있는 **나만의 문서 사이트**가 인터넷에 공개됩니다

---

## 핵심 포인트

!!! success "이 프로젝트에서 배우는 것"
    - AI에게 **프로젝트 전체 구조**를 요청할 수 있다
    - 코드를 몰라도 **설정 파일을 AI가 만들어준다**
    - Git/GitHub를 통해 **무료로 웹사이트를 배포**할 수 있다
    - 문서를 수정하면 **자동으로 사이트에 반영**된다
