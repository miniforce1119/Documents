# 프로젝트 2: YouTube로 AI 오디오 오버뷰 만들기

> **유형**: Chat AI 활용 | **난이도**: :material-star: | **준비물**: 브라우저, Google 계정

---

## 목표

NotebookLM에 YouTube 영상 URL을 넣고, AI가 자동으로 만들어주는 **팟캐스트 형식의 오디오 오버뷰**를 체험합니다.

---

## NotebookLM이란?

Google이 만든 AI 연구 도구입니다. 문서, PDF, 웹사이트, YouTube 영상을 넣으면:

- 내용을 자동으로 **요약**
- 질문에 **소스 기반으로 답변**
- **팟캐스트 형식의 오디오**로 변환 (두 명이 대화하는 형태)

---

## STEP 1. NotebookLM 접속

1. [NotebookLM](https://notebooklm.google.com) 에 접속합니다
2. Google 계정으로 로그인합니다
3. **새 노트북 만들기**를 클릭합니다

---

## STEP 2. YouTube 영상 소스 추가

1. **소스 추가** 버튼을 클릭합니다
2. **YouTube** 를 선택합니다
3. 아래 URL을 붙여넣습니다:

```
https://www.youtube.com/watch?v=f1sr0D13wEY
```

!!! info "한로로 영상"
    이 영상은 테스트용 샘플입니다. 원하는 다른 YouTube 영상을 넣어도 됩니다.

4. **삽입** 버튼을 클릭합니다
5. NotebookLM이 영상 내용을 분석할 때까지 잠시 기다립니다

---

## STEP 3. AI에게 질문하기

소스가 추가되면, 하단 채팅창에서 영상에 대해 질문할 수 있습니다.

### 질문 예시

```
이 영상의 핵심 내용을 3줄로 요약해줘
```

```
이 영상에서 가장 중요한 메시지는 뭐야?
```

```
이 내용을 우리 팀 회의에서 공유할 수 있게 요약해줘
```

---

## STEP 4. AI 오디오 오버뷰 생성

이 프로젝트의 핵심 기능입니다.

1. 화면 우측의 **스튜디오** 패널을 확인합니다
2. **오디오 오버뷰** 섹션에서 **생성** 버튼을 클릭합니다
3. AI가 **두 사람이 대화하는 팟캐스트 형식**의 오디오를 자동 생성합니다
4. 생성이 완료되면 **재생** 버튼을 눌러 들어봅니다

!!! warning "생성 시간"
    오디오 생성에 몇 분이 소요될 수 있습니다. 기다리는 동안 채팅으로 질문을 해보세요.

---

## STEP 5. 추가 소스로 확장 (선택)

NotebookLM은 여러 소스를 동시에 분석할 수 있습니다. 아래를 추가로 넣어보세요:

- **다른 YouTube 영상** URL
- **PDF 문서** 업로드
- **웹사이트 URL** 붙여넣기
- **Google Docs** 연결

여러 소스를 넣은 뒤 오디오 오버뷰를 다시 생성하면, AI가 **모든 소스를 종합해서** 팟캐스트를 만들어줍니다.

---

## 핵심 포인트

!!! success "이 프로젝트에서 배우는 것"
    - AI가 영상/문서를 **이해하고 재구성**할 수 있다
    - 긴 콘텐츠를 **빠르게 파악**하는 데 AI를 활용할 수 있다
    - 여러 자료를 **통합 분석**할 수 있다
    - 콘텐츠를 **다른 형태(오디오)**로 변환할 수 있다
