# 프로젝트 1: 엑셀 데이터로 인포그래픽 만들기

> **유형**: Chat AI 활용 | **난이도**: :material-star: | **준비물**: 브라우저, ChatGPT 계정

---

## 목표

CSV 데이터를 ChatGPT에 업로드하고, 대화만으로 인포그래픽을 만들어봅니다.

---

## STEP 1. 샘플 데이터 다운로드

타이타닉 승객 데이터를 사용합니다. (891명의 승객 정보가 담긴 유명한 데이터셋)

**다운로드 URL:**

```
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv
```

**저장 방법:**

1. 위 URL을 브라우저에서 엽니다
2. ++ctrl+s++ 를 누릅니다
3. 파일 형식을 **모든 파일(\*.\*)** 로 변경
4. 파일 이름을 `titanic.csv`로 지정 후 저장

!!! info "데이터에 포함된 정보"
    승객ID, 생존여부, 객실등급, 이름, 성별, 나이, 동승자 수, 요금, 탑승항구 등

---

## STEP 2. ChatGPT에 데이터 업로드

1. [ChatGPT](https://chat.openai.com)에 접속합니다
2. 채팅창 왼쪽의 **첨부(클립) 아이콘**을 클릭합니다
3. 방금 저장한 `titanic.csv` 파일을 업로드합니다

---

## STEP 3. 프롬프트로 인포그래픽 요청

아래 프롬프트를 복사해서 ChatGPT에 붙여넣으세요.

### 3-1. 데이터 분석 요청

```
이 CSV 파일을 분석해줘.
- 전체 승객 수, 생존율
- 성별/객실등급별 생존율
- 나이 분포
핵심 인사이트 3가지를 정리해줘.
```

### 3-2. 인포그래픽 생성 요청

```
위 분석 결과를 바탕으로 인포그래픽을 만들어줘.
조건:
- 한눈에 보기 좋은 시각적 디자인
- 핵심 숫자는 크게 강조
- 차트(파이, 바 등) 포함
- 한국어로 작성
- 타이타닉호 테마에 맞는 색상 (파란색/남색 계열)
```

### 3-3. 수정 요청 (프롬프트 다듬기 연습)

결과가 마음에 안 들면 자유롭게 수정을 요청해보세요.

```
- 배경색을 더 어둡게 바꿔줘
- 생존율 차트를 파이차트 대신 아이콘으로 표현해줘
- 제목을 "타이타닉호 생존 분석 리포트"로 바꿔줘
- 하단에 출처: Kaggle Titanic Dataset 추가해줘
```

---

## 핵심 포인트

!!! success "이 프로젝트에서 배우는 것"
    - AI에게 **데이터를 주고 분석을 요청**할 수 있다
    - **프롬프트를 구체적으로** 쓸수록 원하는 결과물이 나온다
    - 결과물이 마음에 안 들면 **대화로 수정**할 수 있다
    - 디자인 도구를 몰라도 **시각 자료를 만들 수 있다**
