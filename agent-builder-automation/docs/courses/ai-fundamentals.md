## 1. AI란 무엇인가?

### 1.1 AI의 정의

**AI (Artificial Intelligence, 인공지능)**는 사람처럼 생각하고 학습하는 컴퓨터 프로그램입니다.

#### 쉽게 비유하면:

| 상황 | 사람 | AI |
|------|------|-----|
| 사진 보기 | "이건 고양이야" | "이미지를 분석한 결과, 고양이일 확률 95%" |
| 글 쓰기 | 경험과 지식으로 문장 작성 | 학습한 패턴으로 문장 생성 |
| 번역 | 두 언어를 알고 있어서 번역 | 수많은 번역 예시를 학습해서 번역 |

### 1.2 AI vs 일반 프로그램

#### **일반 프로그램**
```
규칙: "온도가 30도 이상이면 '더워요' 출력"
입력: 32도
출력: 더워요
```
→ 프로그래머가 **모든 규칙을 직접 작성**

#### **AI 프로그램**
```
학습: 수천 개의 [온도, 날씨 설명] 데이터로 학습
입력: 32도
출력: 매우 더운 날씨입니다. 시원한 곳에서 휴식을 취하세요.
```
→ AI가 **데이터에서 패턴을 스스로 학습**

### 1.3 왜 지금 AI가 중요한가?

**3가지 이유:**

1. **데이터 폭발** 📊
   - 매일 생성되는 데이터: 약 2.5조 바이트
   - 사람이 직접 분석하기 불가능

2. **컴퓨팅 파워 증가** 💻
   - GPU, TPU 등 고성능 칩 발전
   - 클라우드 컴퓨팅으로 누구나 사용 가능

3. **알고리즘 발전** 🧠
   - Transformer (2017)
   - GPT, BERT 등 혁신적 모델 등장

#### **Stage 1: 약한 AI (Narrow AI)** ⭐ *현재 우리가 쓰는 AI*

- **특징:** 인간보다 뛰어난 지능
- **현황:** 이론적 개념

## 3. 머신러닝 기초

### 3.1 머신러닝이란?

**머신러닝(Machine Learning, ML)**은 컴퓨터가 데이터에서 스스로 학습하는 기술입니다.

#### 핵심 아이디어:
```
데이터 → 학습 → 패턴 발견 → 예측/판단
```

### 3.2 학습 방식 3가지

![머신러닝 학습 방식](https://www.genspark.ai/api/files/s/QIxutgRO)
*그림 3: 지도 학습, 비지도 학습, 강화 학습 비교*

#### **1) 지도 학습 (Supervised Learning)** 👨‍🏫

**개념:** 정답이 있는 데이터로 학습

**예시:**
```
학습 데이터:
이미지1 + 정답: 개
이미지2 + 정답: 고양이
이미지3 + 정답: 개
...

새로운 이미지 입력 → AI 예측: 개
```

**활용:**
- 스팸 메일 분류
- 질병 진단
- 주가 예측

#### **2) 비지도 학습 (Unsupervised Learning)** 🔍

**개념:** 정답 없이 데이터의 패턴을 스스로 찾음

**예시:**
```
고객 구매 데이터 → AI가 자동으로 그룹화

그룹 A: 주로 전자제품 구매
그룹 B: 주로 화장품 구매
그룹 C: 주로 식품 구매
```

**활용:**
- 고객 세분화
- 이상 거래 탐지
- 추천 시스템

#### **3) 강화 학습 (Reinforcement Learning)** 🎮

**개념:** 시행착오를 통해 보상을 최대화하는 방법을 학습

**예시:**
```
게임 AI:
행동1: 앞으로 이동 → 보상: +1점
행동2: 적과 충돌 → 보상: -10점
행동3: 아이템 획득 → 보상: +5점

반복 학습 → 최적의 전략 발견
```

**활용:**
- 게임 AI (AlphaGo)
- 로봇 제어
- 자율주행

### 3.3 머신러닝의 핵심 요소

#### **데이터 (Data)** 📊
```
많을수록 좋음 ✅
품질이 중요함 ✅
다양할수록 좋음 ✅
```

#### **특성 (Feature)** 🎯
```
예: 집값 예측
특성들:
- 면적
- 방 개수
- 위치
- 건축 연도
- 주변 학교
```

#### **모델 (Model)** 🧠
```
데이터를 학습해서 만들어진 "예측기"
예: 선형 회귀, 의사결정 트리, 신경망
```

#### **학습 (Training)** 🏋️
```
데이터 → 모델 입력 → 예측 → 오차 계산 → 모델 수정
반복 반복 반복... → 정확도 향상
```

## 4. 딥러닝 이해하기

### 4.1 딥러닝이란?

**딥러닝(Deep Learning)**은 머신러닝의 한 종류로, **인간의 뇌를 모방한 신경망**을 사용합니다.

#### 뇌 vs 딥러닝
```
사람 뇌:
뉴런(신경세포) → 시냅스(연결) → 신호 전달

딥러닝:
인공 뉴런 → 가중치(연결 강도) → 정보 전달
```

### 4.2 신경망의 구조

#### **기본 구조**
```
입력층 → [은닉층 1] → [은닉층 2] → ... → 출력층

예: 손글씨 숫자 인식
입력: 28x28 픽셀 이미지 (784개 숫자)
은닉층: 여러 층 (패턴 추출)
출력: 0~9 중 하나
```

#### **"Deep"의 의미**
```
얕은 신경망: 은닉층 1~2개
깊은 신경망: 은닉층 수십~수백 개 ← 딥러닝!
```

### 4.3 딥러닝의 주요 종류

#### **1) CNN (합성곱 신경망)** 🖼️

**특징:** 이미지 인식에 특화

**원리:**
```
이미지 → 특징 추출 (모서리, 패턴) → 분류

활용:
- 얼굴 인식
- 의료 영상 분석
- 자율주행 (물체 인식)
```

#### **2) RNN (순환 신경망)** 📝

**특징:** 순서가 있는 데이터 처리

**원리:**
```
단어1 → 단어2 → 단어3 → 예측

활용:
- 번역
- 음성 인식
- 주가 예측
```

#### **3) Transformer** 🚀

**특징:** 현재 가장 강력한 구조 (ChatGPT, GPT-4 기반)

**원리:**
```
문장 전체를 동시에 분석
단어 간 관계를 "Attention"으로 파악

활용:
- 대화 AI (ChatGPT)
- 번역 (Google 번역)
- 요약, 글쓰기
```

### 4.4 딥러닝 vs 머신러닝

| 구분 | 머신러닝 | 딥러닝 |
|------|----------|--------|
| **데이터** | 적은 데이터로도 가능 | 대량의 데이터 필요 |
| **특징 추출** | 사람이 직접 정의 | AI가 자동으로 학습 |
| **계산** | 일반 CPU로 가능 | GPU/TPU 필요 |
| **정확도** | 중간 | 높음 |
| **예시** | 의사결정 트리, SVM | CNN, Transformer |

## 5. 주요 AI 용어 사전

### 5.1 기본 용어

#### **알고리즘 (Algorithm)** 📐
```
문제를 해결하는 단계적 절차
예: 요리 레시피, 수학 공식
```

#### **모델 (Model)** 🧩
```
학습된 AI의 "지식"
예: GPT-4 모델, BERT 모델
```

#### **학습 (Training)** 📚
```
데이터를 보고 패턴을 익히는 과정
예: 1만 장 고양이 사진으로 학습
```

#### **추론 (Inference)** 🔮
```
학습된 모델로 예측하는 것
예: 새 사진 보고 "고양이다!" 판단
```

#### **파라미터 (Parameter)** ⚙️
```
모델 내부의 "설정값"
예: GPT-4는 약 1.7조 개 파라미터
```

### 5.2 성능 관련 용어

#### **정확도 (Accuracy)** 🎯
```
전체 중 맞춘 비율
예: 100개 중 95개 정답 → 95% 정확도
```

#### **과적합 (Overfitting)** 📉
```
훈련 데이터만 너무 잘 맞춰서 새 데이터는 못 맞추는 현상

비유:
시험 문제만 달달 외워서
실전에서 응용 못 하는 것
```

#### **일반화 (Generalization)** 🌍
```
학습한 내용을 새로운 상황에 적용하는 능력

좋은 AI = 일반화 능력이 높음
```

### 5.3 데이터 관련 용어

#### **데이터셋 (Dataset)** 📦
```
학습에 사용하는 데이터 모음
예: ImageNet (1400만 장 이미지)
```

#### **훈련 세트 (Training Set)** 🏋️
```
모델 학습에 사용하는 데이터
예: 전체의 80%
```

#### **검증 세트 (Validation Set)** ✅
```
모델 성능을 중간 점검하는 데이터
예: 전체의 10%
```

#### **테스트 세트 (Test Set)** 🧪
```
최종 성능을 평가하는 데이터
예: 전체의 10%
```

#### **레이블 (Label)** 🏷️
```
데이터의 정답
예: 이미지 + 레이블(고양이/개)
```

### 5.4 최신 AI 용어

#### **LLM (Large Language Model)** 💬
```
대규모 언어 모델
예: GPT-4, Claude, Gemini
특징: 거대한 텍스트 데이터로 학습
```

#### **프롬프트 (Prompt)** 📝
```
AI에게 주는 명령/질문
예: "Python 코드를 작성해줘"
```

#### **토큰 (Token)** 🎫
```
AI가 처리하는 텍스트 단위
예: "안녕하세요" → [안녕, 하, 세요] (3 토큰)
```

#### **파인튜닝 (Fine-tuning)** 🔧
```
사전 학습된 모델을 특정 작업에 맞게 재학습
예: GPT를 의료 챗봇으로 특화
```

#### **RAG (Retrieval-Augmented Generation)** 🔍
```
외부 지식을 검색해서 답변에 활용
예: 회사 문서를 참고해서 답변
```

#### **할루시네이션 (Hallucination)** 🌫️
```
AI가 거짓 정보를 그럴듯하게 만들어내는 현상
예: 없는 논문을 있다고 주장
```

#### **멀티모달 (Multimodal)** 🎨
```
여러 종류의 데이터를 동시에 처리
예: 텍스트 + 이미지 + 음성
대표: GPT-4V, Gemini
```

## 7. AI 활용 시 알아야 할 것들

### 7.1 AI의 한계

#### **1) 데이터 편향** ⚠️
```
문제:
남성 사진으로만 학습 → 여성 인식 못 함

해결:
다양한 데이터 확보
```

#### **2) 설명 불가능** 🤷
```
문제:
"왜 이렇게 판단했어?" → AI가 설명 못 함

예: 대출 거절 이유를 모름
```

#### **3) 적대적 공격** 🎭
```
문제:
사람 눈엔 똑같은데, AI는 다르게 인식

예: 스티커 하나로 정지 표지판을 속도 제한 표지판으로 인식
```

#### **4) 에너지 소비** ⚡
```
문제:
GPT-3 학습: 약 1,287MWh (일반 가정 120년 전력)

해결:
효율적인 모델 개발 중
```

### 7.2 윤리적 이슈

#### **개인정보 보호** 🔒
```
AI 학습에 내 데이터가 사용되나?
내 사진이 AI 학습에 쓰였나?

→ 데이터 동의, 익명화 필요
```

#### **저작권** ©️
```
AI가 만든 그림/글의 저작권은?
AI가 기존 작품을 학습했다면?

```


### 7.3 AI와 함께 일하는 법

#### **AI는 도구** 🛠️
```
❌ AI가 모든 걸 해줄 거야
✅ AI를 활용해서 내 업무를 효율화

예:
- 초안 작성: AI
- 검토/수정: 사람
```

#### **프롬프트 엔지니어링** 🎯
```
좋은 질문 = 좋은 답변

나쁜 예:
"코드 짜줘"

좋은 예:
"Python으로 CSV 파일을 읽어서
각 열의 평균을 계산하는 코드를 작성해줘.
pandas 라이브러리를 사용하고
주석도 포함해줘."
```

#### **비판적 사고** 🧐
```
AI 답변을 맹신하지 말 것

체크리스트:
□ 출처가 명확한가?
□ 논리적으로 타당한가?
□ 최신 정보인가?
□ 편향되지 않았나?
```

## 📝 요약 정리

### 핵심 포인트 10가지

1. **AI는 데이터에서 학습**하는 프로그램입니다.
2. **머신러닝**은 AI의 한 방법이고, **딥러닝**은 머신러닝의 한 종류입니다.
3. **지도 학습** (정답 있음), **비지도 학습** (정답 없음), **강화 학습** (보상으로 학습)이 있습니다.
4. **LLM** (대규모 언어 모델)이 현재 가장 주목받는 AI입니다.
5. AI는 **이미지, 텍스트, 음성, 비디오** 등 다양한 데이터를 처리합니다.
6. **프롬프트**를 잘 작성하면 AI를 효과적으로 활용할 수 있습니다.
7. AI에는 **편향, 할루시네이션** 등의 한계가 있습니다.
8. AI는 **도구**이며, 사람의 판단이 여전히 중요합니다.
9. **윤리적 사용**이 필수입니다 (개인정보, 저작권 등).
10. 지금 바로 **ChatGPT 등으로 실습**을 시작하세요!

## 💬 자주 묻는 질문

### Q1. AI를 배우려면 수학을 잘해야 하나요?
**A:** AI를 **사용**하는 데는 수학이 필요 없습니다. AI를 **개발**하려면 선형대수, 미적분, 확률이 필요하지만, 도구로 활용하는 것은 누구나 가능합니다.

### Q2. 프로그래밍을 모르는데 AI를 배울 수 있나요?
**A:** 네! ChatGPT, Midjourney 같은 AI 도구는 코딩 없이 사용 가능합니다. 다만, 더 깊이 있는 활용을 위해서는 Python 기초를 추천합니다.

### Q3. AI가 내 직업을 대체할까요?
**A:** 반복적인 업무는 자동화될 수 있지만, 창의성, 판단, 대인 관계가 필요한 일은 여전히 사람이 중요합니다. 오히려 AI를 활용하는 능력이 경쟁력이 됩니다.

### Q4. 무료로 AI를 배울 수 있나요?
**A:** 네! YouTube, Coursera, Fast.ai, Google Colab 등 무료 자료가 많습니다. ChatGPT 무료 버전으로도 충분히 연습할 수 있습니다.

### Q5. AI 답변을 어디까지 믿어야 하나요?
**A:** AI는 도구일 뿐입니다. 중요한 결정은 반드시 사람이 검증해야 합니다. 특히 의료, 법률, 금융 등 전문 분야는 전문가 확인이 필수입니다.
