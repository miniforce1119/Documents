# MkDocs Documentation Workflow

## 개요

이 문서는 Agent Builder를 통해 자동으로 생성된 문서입니다.

## 주요 기능

### 1. 자동 문서 생성
- AI 기반 컨텐츠 생성
- Markdown 포맷 자동 변환
- GitHub 연동

### 2. 배포 자동화
- Git commit/push 자동화
- MkDocs build 연동
- 실시간 미리보기

## 사용 방법

```bash
python export_agent_to_docs.py --input agent_output.txt --category analysis --build
```

## 결론

이 workflow를 통해 문서화 작업을 자동화할 수 있습니다.
