강의 소개

본 강의는 프로그래밍 경험이 없는 분들을 대상으로, 최신 AI 기술인 'AI Agent(인공지능 비서)'를 직접 만들어보는 과정입니다. 복잡한 코딩 대신 'Langflow'라는 노코드(No-Code) 도구를 사용하여, 블록을 조립하듯이 쉽고 재미있게 AI를 배워봅니다.

🎯 학습 목표
  • 인공지능(AI)과 AI Agent의 기본 개념을 이해합니다.
  • 코딩 없이 AI를 개발할 수 있는 Langflow 도구 사용법을 익힙니다.
  • 내 업무나 생활에 도움을 주는 간단한 AI 챗봇을 직접 만듭니다.

수강 전 준비사항

  • 인터넷이 연결된 PC 또는 노트북 (Windows/Mac)
  • OpenAI 계정 (ChatGPT 사용 계정)
  • 새로운 기술을 배우고자 하는 열린 마음

Part 1. AI 기초 이해하기

AI Agent를 만들기 전에, 우리가 다룰 기술이 무엇인지 간단히 알아봅니다. 어려운 용어보다는 실생활 예시를 중심으로 쉽게 설명하겠습니다.

1. 인공지능(AI)이란 무엇인가?

인공지능(Artificial Intelligence, AI)은 사람처럼 생각하고 학습하며 문제를 해결할 수 있는 컴퓨터 프로그램입니다. 마치 사람이 경험을 통해 배우듯이, AI도 많은 데이터를 학습하여 점점 똑똑해집니다.

📱 우리가 일상에서 만나는 AI

  • 스마트폰 음성인식: "시리야", "OK 구글" - 내 말을 듣고 이해하는 AI
  • 넷플릭스 추천: 내가 본 영화를 분석해서 좋아할 만한 콘텐츠를 추천
  • ChatGPT: 질문하면 사람처럼 자연스럽게 대답해주는 AI
  • 자동 번역: 한국어를 영어로, 영어를 일본어로 실시간 번역
  • 스팸메일 필터: 위험한 메일을 자동으로 걸러주는 AI

🕐 AI의 발전 과정

시기 주요 발전
1950년대 AI라는 개념이 처음 등장. 간단한 게임(체스)을 하는 프로그램
2010년대 딥러닝 기술 발전. 사진 속 사물을 인식하고 음성을 이해하기 시작
2022년 이후 ChatGPT 등장. 사람처럼 대화하고 글을 쓰는 AI 시대 본격화
현재(2024년) AI Agent 시대. 단순 대화를 넘어 스스로 작업을 수행하는 AI

2. AI Agent는 무엇이 다를까?

일반 AI가 단순히 질문에 답하는 '똑똑한 사전'이라면, AI Agent는 스스로 생각하고 도구를 사용하여 작업을 완성하는 '똑똑한 비서'입니다.

  2. 📊 업무 자동화 비서
    "이번 주 회의록 요약해서 이메일로 보내줘" ➜ 문서 읽기 ➜ 핵심 내용 요약 ➜ 이메일 작성 ➜ 자동 발송
  3. 🛒 쇼핑 도우미
    "노트북 추천해줘" ➜ 예산 확인 ➜ 여러 쇼핑몰 가격 비교 ➜ 리뷰 분석 ➜ 최적의 제품 추천
  4. 📚 학습 도우미
    "AI에 대해 공부하고 싶어" ➜ 수준 파악 ➜ 학습 자료 검색 ➜ 맞춤 커리큘럼 작성 ➜ 퀴즈 생성
✅ AI Agent의 3가지 핵심 능력
  • 인식: 사용자가 원하는 것이 무엇인지 정확히 이해
  • 행동: 필요한 도구(검색, 계산, 파일 읽기 등)를 스스로 선택해서 사용
  • 완성: 여러 단계를 거쳐 최종 결과물을 만들어냄

3. Langflow 소개

Langflow는 복잡한 프로그래밍 언어(Python, JavaScript 등)를 전혀 몰라도, 화면에서 블록을 끌어다 놓는 드래그 앤 드롭(Drag & Drop) 방식만으로 강력한 AI Agent를 만들 수 있게 해주는 노코드 도구입니다.

💡 노코드(No-Code)란? 소스 코드를 직접 작성하지 않고, 그래픽 인터페이스(GUI)를 통해 소프트웨어를 개발하는 방식을 말합니다. 마치 레고 블록을 조립하거나 파워포인트에서 도형을 배치하는 것과 비슷합니다.

🎯 Langflow를 선택해야 하는 이유

장점 설명
👶 초보자 친화적 프로그래밍 지식 없이도 시각적으로 AI 흐름을 설계 가능
⚡ 빠른 프로토타입 아이디어를 몇 분 만에 실제 작동하는 AI로 구현
🔧 다양한 통합 OpenAI, Google, 데이터베이스 등 수십 가지 도구와 연결 가능
🆓 무료 오픈소스 소프트웨어 자체는 완전 무료 (단, 연결된 AI 서비스는 별도 비용 발생 가능)
🌐 활발한 커뮤니티 전 세계 개발자들이 만든 템플릿과 사례를 참고 가능

🆚 다른 노코드 AI 도구와의 비교

도구 특징 장점 단점
Langflow 오픈소스, 흐름도 기반 무료, 유연함, 커스터마이징 자유 설치 필요
Zapier 업무 자동화 특화 사용 쉬움, 클라우드 유료, AI 기능 제한적
Make.com 시나리오 자동화 직관적 UI 유료 구독 필요
❗ 이 강의에서 Langflow를 선택한 이유
  • 완전 무료로 학습 가능
  • AI Agent 제작에 특화된 기능
  • 배우면 다른 노코드 도구도 쉽게 활용 가능
  • 기업 실무에서도 활용도가 높음

🏗️ Langflow로 만들 수 있는 것들

  • ✅ 고객 상담 챗봇 (24시간 자동 응대)
  • ✅ 문서 요약 및 분석 도구 (PDF, 워드 파일 자동 요약)
  • ✅ 데이터 분석 비서 (엑셀 데이터를 읽고 리포트 작성)
  • ✅ 콘텐츠 생성 도구 (블로그 글, 광고 문구 자동 작성)
  • ✅ 개인 비서 (일정 관리, 이메일 작성, 정보 검색)
🎓 이 강의를 마치면 여러분은 위와 같은 실전 AI Agent를 직접 만들 수 있는 능력을 갖추게 됩니다!

Part 2. 개발 환경 준비 (실습)

Langflow를 사용하기 위해 Windows 컴퓨터에 필요한 환경을 설정하는 단계입니다. 모든 과정을 스크린샷과 함께 천천히 따라해 보세요. 약 30-40분 정도 소요됩니다.

⚠️ 시작하기 전 체크리스트
  • ✅ Windows 10 이상 운영체제
  • ✅ 인터넷 연결 (설치 파일 다운로드 필요)
  • ✅ 관리자 권한 (프로그램 설치 시 필요)
  • ✅ 여유 저장 공간 최소 2GB 이상

1. Python 설치하기

Python(파이썬)은 Langflow를 실행하기 위한 필수 프로그램입니다. 마치 엑셀 파일을 열기 위해 MS Office가 필요한 것처럼, Langflow를 실행하려면 Python이 설치되어 있어야 합니다.

Step 1-1: 기존 Python 설치 확인

먼저 컴퓨터에 Python이 이미 설치되어 있는지 확인해봅시다.

  1. 1키보드에서 Windows 키 + R을 동시에 누릅니다.
  2. 2"실행" 창이 뜨면 cmd를 입력하고 확인을 클릭합니다.
  3. 3검은 화면(명령 프롬프트)이 나타나면 다음 명령어를 입력하고 Enter 키를 누릅니다:
    python --version
💡 결과 확인
  • 성공: "Python 3.10.5" 같은 버전 번호가 나오면 이미 설치되어 있습니다 → Step 1-3으로 이동
  • 실패: "명령을 인식할 수 없습니다" 에러가 나오면 설치가 필요합니다 → Step 1-2 진행

  1. 1웹 브라우저를 열고 주소창에 입력: https://www.python.org

2. Langflow 설치하기

Python이 준비되었으니 이제 본격적으로 Langflow를 설치합니다. Langflow는 Python 프로그램 중 하나로, pip라는 도구를 통해 쉽게 설치할 수 있습니다.

💡 pip란? Python 프로그램들을 설치하고 관리해주는 도구입니다. Python을 설치하면 자동으로 함께 설치됩니다. 앱스토어에서 앱을 다운받는 것과 비슷합니다.

Step 2-1: 명령 프롬프트 열기

  1. 1Windows 키 + R → cmd 입력 → 확인
  2. 2검은 화면(명령 프롬프트)이 열립니다.

Step 2-2: Langflow 설치 명령어 실행

다음 명령어를 정확히 입력하고 Enter 키를 누릅니다:

pip install langflow
💡 복사 붙여넣기 방법
  • 위 명령어를 마우스로 드래그해서 복사 (Ctrl + C)
  • 명령 프롬프트 창에서 우클릭하면 자동으로 붙여넣기 됩니다
  • 또는 Ctrl + V로 붙여넣기

설치 시작: 명령어를 입력하면 자동으로 다운로드 및 설치가 진행됩니다.

[이미지: pip install langflow 실행 중 화면 - 다운로드 진행 상황]
그림 2-4. Langflow 설치 진행 화면

Step 2-3: 설치 완료 확인

설치가 완료되면 (약 2-3분 소요) 다음과 같은 메시지가 나타납니다:

  • "Successfully installed langflow-x.x.x" (버전 번호는 다를 수 있음)
  • 다시 C:\Users\사용자명> 형태의 프롬프트가 나타남
⚠️ 에러가 발생한다면?

에러 1: "pip을 찾을 수 없습니다"

  • → Python 설치 시 PATH 추가를 하지 않았을 가능성
  • → Python을 다시 설치하고 "Add Python to PATH" 체크 필수

에러 2: "Permission denied" 권한 오류

  • → 명령 프롬프트를 관리자 권한으로 실행
  • → 시작 메뉴에서 "cmd" 검색 → 우클릭 → "관리자 권한으로 실행"

3. OpenAI API 키 발급받기

Langflow로 AI Agent를 만들려면 OpenAI API 키가 필요합니다. 이것은 OpenAI의 AI 모델(GPT)을 사용하기 위한 비밀번호 같은 것입니다.

💡 API 키란? 소프트웨어가 외부 서비스에 접근할 때 사용하는 인증 코드입니다. 은행 앱에서 공인인증서를 쓰는 것과 비슷한 개념입니다.

Step 3-1: OpenAI 계정 만들기

  1. 1웹 브라우저에서 https://platform.openai.com 접속
  2. 2우측 상단 "Sign up" 클릭
  3. 3이메일 주소와 비밀번호 입력 (또는 Google 계정으로 가입)
  4. 4이메일 인증 완료

Step 3-2: API 키 생성하기

  1. 1로그인 후 왼쪽 메뉴에서 "API keys" 클릭
  2. 2"Create new secret key" 버튼 클릭

6. 문제 해결 (Troubleshooting)

설치 과정에서 자주 발생하는 문제와 해결 방법입니다.

🔧 문제 1: "python을 찾을 수 없습니다"

증상 cmd에서 python 명령어 입력 시 "내부 또는 외부 명령... 인식할 수 없습니다" 에러

원인: Python이 PATH에 추가되지 않았습니다.

해결:

  1. Python을 완전히 삭제 (제어판 → 프로그램 제거)
  2. 다시 설치하되 "Add Python to PATH" 체크 필수
  3. 컴퓨터 재부팅

🔧 문제 2: Langflow 실행 시 포트 에러

증상 "Address already in use" 또는 포트 7860이 이미 사용 중이라는 에러

원인: 다른 프로그램이 7860 포트를 사용하고 있습니다.

해결:

  1. 다른 포트로 실행:
    python -m langflow run --port 7861
  2. 브라우저에서 http://localhost:7861로 접속

🔧 문제 3: 브라우저 페이지가 로딩되지 않음

증상 브라우저에서 "연결할 수 없음" 또는 무한 로딩

해결:

  1. cmd 창에서 Langflow가 제대로 실행 중인지 확인 (에러 메시지 확인)
  2. 방화벽 설정: Windows 보안 → 방화벽 → Python 허용
  3. 다른 브라우저 시도 (크롬 → 엣지 또는 그 반대)
  4. 브라우저 캐시 삭제 후 재시도

🔧 문제 4: OpenAI API 키 오류

증상 Langflow에서 "Invalid API key" 에러

해결:

  1. API 키를 정확히 복사했는지 확인 (앞뒤 공백 없이)
  2. OpenAI 플랫폼에서 키가 활성화 상태인지 확인
  3. 결제 정보가 등록되어 있는지 확인 (무료 크레딧 사용 중이어도 필요)
💬 도움이 더 필요하다면?
  • 강사에게 질문하기
  • 옆 사람과 화면 비교해보기
  • Langflow 공식 문서: https://docs.langflow.org

Part 5. 사내 AI 환경 이해하기

지금까지 OpenAI(외부 AI)를 사용해서 AI Agent를 만들어봤습니다. 이제 우리 회사가 자체적으로 운영하는 사내 AI 환경에 대해 알아보고, 외부 환경과 무엇이 다른지, 어떻게 활용하는지 배워보겠습니다.

💡 이 섹션의 목표 외부 AI(OpenAI)와 사내 AI의 차이점을 이해하고, Langflow에서 사내 AI로 전환하는 방법을 익힙니다.

1. 외부 AI vs 사내 AI: 무엇이 다를까?

지금까지 사용한 OpenAI는 미국 회사가 운영하는 외부 서비스입니다. 반면 우리 회사의 사내 AI는 회사 내부 서버에서 작동하는 자체 AI입니다.

🌐 외부 AI (OpenAI, Claude 등)

특징 설명
위치 외부 클라우드 서버 (미국, 유럽 등)
접근 방법 인터넷 연결 필수 + API 키 필요
데이터 처리 ❌ 입력한 데이터가 외부로 전송됨
비용 사용량에 따라 과금 (Token 단위)
성능 ⭐⭐⭐⭐⭐ 최신 기술, 지속적 업데이트
사용 예시 개인 학습, 프로토타입 제작, 민감하지 않은 업무

🏢 사내 AI (온프레미스)

특징 설명
위치 회사 내부 서버 (사내 데이터센터)
접근 방법 사내망 접속 (VPN 또는 사무실 네트워크)
데이터 처리 ✅ 모든 데이터가 회사 내부에서만 처리 (보안 우수)
비용 초기 구축 비용 큼, 이후 사용량 무제한
성능 ⭐⭐⭐⭐ 외부 AI 대비 약간 낮을 수 있음
사용 예시 고객 정보, 재무 데이터, 기밀 문서 등 민감한 업무
[이미지: 외부 AI와 사내 AI의 데이터 흐름 비교 다이어그램]
그림 5-1. 외부 AI는 데이터가 인터넷을 통해 외부로, 사내 AI는 회사 내부에서만 처리

2. 우리 회사가 사내 AI를 선택한 이유

회사는 막대한 비용을 들여 자체 AI 시스템을 구축했습니다. 왜 외부 AI를 쓰지 않고 직접 만들었을까요?

🔒 이유 1: 데이터 보안 (가장 중요!)

❗ 실제 사례

상황: A팀이 외부 AI에 고객 계약서를 업로드해서 요약을 요청
문제: 고객 개인정보(이름, 연락처, 계약 금액)가 외부 서버로 전송됨
결과: 정보 보호법 위반 가능성, 회사 이미지 타격 위험

사내 AI의 장점:

  • ✅ 고객 정보, 재무 데이터 등 민감한 정보를 안전하게 처리
  • ✅ 데이터가 절대 외부로 유출되지 않음
  • ✅ 정보 보호법, 금융 규정 등 법적 요구사항 준수
  • ✅ 고객과 주주에게 신뢰 제공

💰 이유 2: 장기적 비용 절감

구분 외부 AI (OpenAI) 사내 AI
초기 비용 거의 없음 (무료 가입) 매우 큼 (서버, 모델 구축)
월 운영비 사용량에 비례 (무제한 증가 가능) 고정 비용 (전기, 관리 인력)
3년 후 💸 수억원 지출 가능 ✅ 초기 투자 회수, 이후 저렴
💡 회사 입장에서는 직원 1,000명이 매일 AI를 쓴다고 가정하면, 외부 AI는 매달 수천만원이 나갑니다. 사내 AI는 초기 투자는 크지만 장기적으로는 훨씬 경제적입니다.

🎨 이유 3: 우리 회사에 맞춘 커스터마이징

  • 회사 전문 용어 학습: 우리 회사 제품명, 부서 약어, 업무 프로세스를 미리 학습
  • 사내 문서 연결: 내부 위키, 업무 매뉴얼 등을 AI가 자동으로 참고
  • 정책 반영: 회사 규정에 맞게 AI의 응답 방식을 조정 가능
🎯 예시 외부 AI: "죄송하지만 귀사의 내부 프로세스는 모릅니다"
사내 AI: "출장 신청은 인사포털 → 전자결재 → [출장] 메뉴에서 하시면 됩니다!"

3. 사내 AI 시스템 소개

우리 회사의 사내 AI는 다음과 같이 구성되어 있습니다.

🖥️ 시스템 구조

구성 요소 설명
웹 인터페이스 ChatGPT처럼 브라우저에서 바로 사용 가능한 채팅 화면 제공
API 엔드포인트 Langflow 같은 외부 도구에서 연결할 수 있는 API 제공
LLM 모델 오픈소스 모델 기반 (예: Llama, Mistral 등을 회사에 맞게 튜닝)

🔑 접속 방법

⚠️ 주의사항
  • 사내 AI는 회사 네트워크(사무실 또는 VPN)에 연결된 상태에서만 사용 가능합니다
  • API 키는 절대 외부에 공유하지 마세요 (보안 위반)
  • 개인적인 용도로 사용하지 마세요 (모든 대화 기록이 저장됩니다)

4. Langflow에서 사내 AI로 전환하기

🔄 전환 실습: Part 4에서 만든 요리 봇을 사내 AI로 전환하기

  2. 키보드 Delete 키를 눌러 삭제

  2. Custom LLM 또는 OpenAI-Compatible 블록을 캔버스로 드래그
  3. Prompt와 Chat Output 사이에 배치

Step 3: 사내 AI 주소 설정

새로 추가한 Custom LLM 블록을 클릭하고 다음 정보를 입력합니다:

항목 입력값
Base URL http://internal-ai.company.com/api (IT팀에서 받은 주소)
API Key IT팀에서 발급받은 인증키 입력
Model Name company-llm-v1 (IT팀 확인)
[이미지: Custom LLM 블록 설정 화면 스크린샷]
그림 5-2. 사내 AI 연결 설정 화면

Step 4: 연결 및 테스트

  1. Prompt → Custom LLM → Chat Output 순서로 다시 연결
  2. Play 버튼을 눌러 채팅창 실행
  3. 똑같이 "계란이랑 양파가 있어"라고 입력해서 테스트
🎉 성공! 이제 같은 Agent가 회사 AI로 작동합니다! 프롬프트도, 흐름도 그대로인데 AI만 바뀐 것입니다.

5. 어떤 상황에 어떤 AI를 써야 할까?

이제 두 가지 AI를 모두 쓸 수 있게 되었습니다. 상황에 따라 적절히 선택하세요.

⚖️ 선택 가이드

이럴 때는 외부 AI (OpenAI) ✅ 이럴 때는 사내 AI ✅
• 개인 학습 및 연습 • 고객 정보가 포함된 업무
• 공개된 정보 활용 (뉴스, 일반 지식) • 재무, 계약, 인사 데이터 처리
• 빠른 프로토타입 제작 • 사내 문서 분석 (보고서, 매뉴얼)
• 최신 기능 테스트 • 정식 배포용 서비스 개발
• 집에서 개인 프로젝트 • 사무실에서 업무용 Agent
❗ 절대 외부 AI에 올리면 안 되는 것
  • ❌ 고객 이름, 연락처, 주민등록번호
  • ❌ 회사 재무제표, 매출 데이터
  • ❌ 계약서, 제안서 원본
  • ❌ 사내 시스템 비밀번호, API 키
  • ❌ 아직 발표되지 않은 신제품 정보

💡 판단 기준: "이 내용이 신문에 나와도 괜찮은가?" → 아니라면 사내 AI 사용!

6. 실습: 사내 환경으로 실무 Agent 만들기

이제 실제 업무에 활용 가능한 Agent를 사내 AI로 만들어봅시다.

📋 프로젝트: 사내 문서 요약 봇

목표: 회의록 파일을 업로드하면 핵심 내용을 3줄로 요약해주는 봇

💡 왜 사내 AI를 써야 할까? 회의록에는 프로젝트명, 담당자 이름, 예산 등 민감한 정보가 포함되어 있어 외부 AI 사용 불가!

만들어볼 컴포넌트 구성:

  1. File Input - 파일 업로드 받기
  2. Text Splitter - 긴 문서를 나누기
  3. Prompt - "다음 회의록을 3줄로 요약하세요"
  4. Custom LLM (사내 AI) - 요약 수행
  5. Chat Output - 결과 출력

이제 여러분은:

  • ✅ 외부 AI와 사내 AI의 차이를 이해했습니다
  • ✅ 상황에 맞는 AI를 선택할 수 있습니다
  • ✅ Langflow에서 두 가지 환경을 자유롭게 전환할 수 있습니다

실무에서는 개발은 외부 AI로 빠르게, 배포는 사내 AI로 안전하게 하는 전략을 추천합니다!

용어 정리

LLM (Large Language Model)
거대 언어 모델. 방대한 텍스트 데이터를 학습하여 인간처럼 언어를 이해하고 생성하는 AI 모델 (예: GPT-4).
Prompt (프롬프트)
AI에게 원하는 결과를 얻기 위해 입력하는 명령어 혹은 질문.
API Key
내 프로그램이 OpenAI 같은 외부 서비스와 통신할 수 있게 해주는 비밀번호 같은 열쇠.

자주 묻는 질문 (Q&A)

Q. Langflow는 무료인가요?
A. 네, Langflow 소프트웨어 자체는 오픈소스로 무료입니다. 단, 연결해서 사용하는 OpenAI 모델 등은 사용량에 따라 비용이 발생할 수 있습니다.

Q. 만든 에이전트를 다른 사람에게 공유할 수 있나요?
A. 네, Export 기능을 통해 JSON 파일로 저장하여 다른 사람에게 전달할 수 있습니다.
