Part 1. AI 기초 이해하기

AI Agent를 만들기 전에, 우리가 다룰 기술이 무엇인지 간단히 알아봅니다. 어려운 용어보다는 실생활 예시를 중심으로 쉽게 설명하겠습니다.

1. 인공지능(AI)이란 무엇인가?

인공지능(Artificial Intelligence, AI)은 사람처럼 생각하고 학습하며 문제를 해결할 수 있는 컴퓨터 프로그램입니다. 마치 사람이 경험을 통해 배우듯이, AI도 많은 데이터를 학습하여 점점 똑똑해집니다.

📱 우리가 일상에서 만나는 AI

  • 스마트폰 음성인식: "시리야", "OK 구글" - 내 말을 듣고 이해하는 AI
  • 넷플릭스 추천: 내가 본 영화를 분석해서 좋아할 만한 콘텐츠를 추천
  • ChatGPT: 질문하면 사람처럼 자연스럽게 대답해주는 AI

2. AI Agent는 무엇이 다를까?

일반 AI가 단순히 질문에 답하는 '똑똑한 사전'이라면, AI Agent는 스스로 생각하고 도구를 사용하여 작업을 완성하는 '똑똑한 비서'입니다.

4. ChatGPT 웹 UI vs API 사용 방식의 차이 🆕

지금까지 API 키를 발급받았습니다. 그런데 "왜 API를 써야 하지? 그냥 ChatGPT 웹사이트에서 채팅하면 안 되나?"라는 의문이 들 수 있습니다. 좋은 질문입니다!

우리가 일상적으로 사용하는 ChatGPT 웹사이트(웹 UI)와 Langflow에서 사용하는 API 방식은 같은 AI를 사용하지만 접근 방법이 다릅니다. 이 차이를 이해하면 Langflow의 가치를 더 명확히 알 수 있습니다.

🌐 방식 1: 웹 UI 사용 (채팅 인터페이스)

ChatGPT 웹사이트에 접속해서 채팅창에 질문을 입력하는 방식입니다. 우리가 가장 익숙한 방법이죠.

✅ 장점
  • 직관적: 카카오톡처럼 쉬움
  • 빠른 시작: 로그인만 하면 바로 사용 가능
  • 비전공자 친화적: 기술 지식 불필요
❌ 단점
  • 수동 작업: 매번 손으로 입력해야 함
  • 반복 불가: 똑같은 질문을 100번 하려면 100번 복사 붙여넣기
  • 연동 불가: 다른 프로그램과 연결 어려움

예시: "내일 날씨 알려줘" → 채팅창에 입력 → AI 답변 확인 (한 번의 대화)

🔌 방식 2: API 사용 (프로그래밍 연동)

API(Application Programming Interface)는 프로그램이 AI와 대화하는 방식입니다. Langflow가 바로 이 방식을 사용합니다.

✅ 장점
  • 자동화 가능: 프로그램이 알아서 수천 번도 실행
  • 대량 처리: 1,000개 문서를 한 번에 분석 가능
  • 시스템 연동: 회사 ERP, 챗봇, 웹사이트에 내장 가능
  • 비용 효율: 사용한 만큼만 과금 (토큰 단위)
❌ 단점
  • 기술 필요: 약간의 설정 지식 필요 (하지만 Langflow가 쉽게 만들어줌!)
  • 비용 계산 복잡: 토큰 단위 과금 (하지만 대량 사용 시 저렴)

예시: Langflow로 만든 AI Agent가 자동으로 매일 아침 날씨를 확인하고 이메일 전송

⚖️ 비교표: 웹 UI vs API

구분 웹 UI (채팅) API (Langflow 등)
접근 방법 브라우저로 웹사이트 접속 프로그램이 코드로 호출
비용 구조 월 구독료 (무제한 또는 정량) 사용량 기반 (토큰당 과금)
작업 횟수 수동 입력 (1회씩) 자동 반복 (무제한)
활용 범위 개인 학습, 간단한 질문 자동화, 시스템 통합, 대량 처리

💡 언제 무엇을 써야 할까?

🌐 웹 UI를 쓰세요:

  • 간단한 질문이나 아이디어 브레인스토밍
  • AI가 처음이라 연습하고 싶을 때
  • 한두 번 물어볼 내용

🔌 API(Langflow)를 쓰세요:

  • 똑같은 작업을 반복해야 할 때 (예: 매일 보고서 요약)
  • 회사 시스템에 AI를 내장하고 싶을 때
  • 여러 단계를 자동화하고 싶을 때 (예: 파일 읽기 → 요약 → 이메일 전송)

🎯 Langflow가 API 방식을 사용하는 이유

Langflow는 "노코드로 API를 쉽게 사용하게 해주는 도구"입니다!

일반적으로 API를 사용하려면 Python 코드를 작성해야 하지만, Langflow는 블록을 연결하는 것만으로 자동으로 API 호출 코드를 생성해줍니다.

👉 쉬움 + 자동화의 장점을 모두 갖춘 것이 Langflow의 핵심 가치입니다.

💡 요약
  • ChatGPT 웹사이트 = 연습하고 배우는 곳
  • Langflow + API = 실제 업무에 적용하는 도구
지금부터는 API를 사용하는 Langflow로 더 강력한 AI Agent를 만들어봅시다!

3. 데이터 흐름과 연결 규칙

컴포넌트들은 점(Handle)과 선(Edge)으로 연결됩니다. 올바르게 연결해야 데이터가 흐를 수 있습니다.

🔌 연결 규칙 (Matching)

💡 같은 색깔끼리 연결하세요!
  • 🔵 Text (파란색) → Text: 일반적인 글자 데이터
  • 🟣 Message (보라색) → Message: 대화 기록이나 채팅 메시지
  • 🟠 Data (주황색) → Data: 파일이나 문서 데이터
  • 🟢 Model (초록색) → Model: AI 모델 자체

만약 연결선이 빨간색으로 변하거나 연결되지 않는다면, 데이터 타입이 맞지 않는 것입니다.

🗂️ 프로젝트 4: 문서 기반 Q&A 봇 (RAG 입문) 🆕

이번에는 가장 실무에서 많이 쓰이는 기능을 배워봅니다. 바로 RAG(Retrieval-Augmented Generation)입니다. 어려운 용어지만, 개념은 정말 간단합니다!

💡 RAG가 뭔가요?

🎯 초간단 비유

일반 AI: 학생이 시험을 볼 때 머릿속 기억만 의지하는 것
RAG AI: 학생이 시험을 볼 때 참고서를 펼쳐놓고 보는 것

👉 AI에게 "이 문서를 참고해서 대답해"라고 자료를 주는 기술입니다!

🤔 왜 RAG가 필요한가?

일반 AI(GPT-4)의 한계:

  • ❌ 최신 정보를 모름: 2023년 10월 이후 뉴스나 정보는 학습 안 됨
  • ❌ 회사 내부 정보를 모름: 우리 회사 복리후생, 휴가 규정, 제품 매뉴얼 등
  • ❌ 가끔 거짓말을 함: 모르는 내용을 그럴듯하게 지어냄 (환각, Hallucination)

RAG를 쓰면:

  • ✅ 정확한 답변: 실제 문서 내용을 기반으로 답변
  • ✅ 최신 정보 반영: 오늘 작성한 문서도 바로 활용 가능
  • ✅ 사내 정보 활용: 회사 규정, 매뉴얼, FAQ 등을 AI가 읽고 답변
  • ✅ 출처 표시: "이 내용은 문서 3페이지에서 가져왔어요"라고 알려줄 수 있음

🎯 실습 목표: 회사 복리후생 FAQ 봇 만들기

시나리오: 직원들이 자주 묻는 "연차는 몇 개인가요?", "경조사비는 얼마인가요?" 같은 질문에 PDF 복리후생 안내서를 읽고 자동으로 답변하는 봇을 만듭니다.

Step 1: 문서 준비

✅ 실습용 문서 예시

간단한 텍스트 파일(TXT) 또는 PDF를 준비하세요. 예를 들어:

복리후생_안내서.txt
---
우리 회사 복리후생 안내

1. 연차: 입사 1년차 15개, 2년차부터 매년 1개씩 추가 (최대 25개)
2. 경조사비: 결혼 30만원, 출산 20만원
3. 중식 지원: 1일 1만원 식비 지원
4. 건강검진: 매년 종합검진 무료 제공
---

Step 2: Langflow 컴포넌트 배치

이번에는 5개의 컴포넌트가 필요합니다. 다음 순서대로 연결하세요:

File → Text Splitter → Vector Store (FAISS) → Retriever → Prompt → OpenAI → Chat Output

각 블록의 역할:

컴포넌트 역할
File 📄 복리후생_안내서.txt 파일을 읽어옵니다
Text Splitter ✂️ 긴 문서를 작은 조각(chunk)으로 나눕니다 (예: 문단별로 나누기)
Vector Store (FAISS) 🗄️ 나눈 조각들을 "검색 가능한 형태"로 저장합니다 (벡터 데이터베이스)
Retriever 🔍 사용자 질문과 가장 관련 있는 문서 조각을 찾아옵니다
Prompt 📝 찾아온 문서 내용을 AI에게 "이 자료를 참고해"라고 전달
OpenAI 🧠 문서 내용을 읽고 사용자 질문에 답변 생성
Chat Output 💬 최종 답변을 화면에 표시

🌟 좋은 프롬프트의 5가지 원칙

  4. 단계별로 생각하게 하라 (Chain of Thought): "단계별로 설명해", "이유를 먼저 말해"라고 지시하세요.
  5. 제약 조건을 걸어라: "비속어 금지", "이모지 사용 필수", "3문장 이내" 등 규칙을 정하세요.

Part 5. 사내 AI 환경 이해하기

지금까지 OpenAI(외부 AI)를 사용해서 AI Agent를 만들어봤습니다. 이제 우리 회사가 자체적으로 운영하는 사내 AI 환경에 대해 알아보고, 외부 환경과 무엇이 다른지, 어떻게 활용하는지 배워보겠습니다.

💡 이 섹션의 목표 외부 AI(OpenAI)와 사내 AI의 차이점을 이해하고, Langflow에서 사내 AI로 전환하는 방법을 익힙니다.

1. 외부 AI vs 사내 AI: 무엇이 다를까?

지금까지 사용한 OpenAI는 미국 회사가 운영하는 외부 서비스입니다. 반면 우리 회사의 사내 AI는 회사 내부 서버에서 작동하는 자체 AI입니다.

그림 5-1. 외부 AI는 데이터가 인터넷을 통해 외부로, 사내 AI는 회사 내부에서만 처리

2. 우리 회사가 사내 AI를 선택한 이유

회사는 막대한 비용을 들여 자체 AI 시스템을 구축했습니다. 왜 외부 AI를 쓰지 않고 직접 만들었을까요?

🔒 이유 1: 데이터 보안 (가장 중요!)

❗ 실제 사례

상황: A팀이 외부 AI에 고객 계약서를 업로드해서 요약을 요청
문제: 고객 개인정보(이름, 연락처, 계약 금액)가 외부 서버로 전송됨
결과: 정보 보호법 위반 가능성, 회사 이미지 타격 위험

사내 AI의 장점:

  • ✅ 고객 정보, 재무 데이터 등 민감한 정보를 안전하게 처리
  • ✅ 데이터가 절대 외부로 유출되지 않음
  • ✅ 정보 보호법, 금융 규정 등 법적 요구사항 준수
  • ✅ 고객과 주주에게 신뢰 제공

💰 이유 2: 장기적 비용 절감

구분 외부 AI (OpenAI) 사내 AI
초기 비용 거의 없음 (무료 가입) 매우 큼 (서버, 모델 구축)
월 운영비 사용량에 비례 (무제한 증가 가능) 고정 비용 (전기, 관리 인력)
3년 후 💸 수억원 지출 가능 ✅ 초기 투자 회수, 이후 저렴
💡 회사 입장에서는 직원 1,000명이 매일 AI를 쓴다고 가정하면, 외부 AI는 매달 수천만원이 나갑니다. 사내 AI는 초기 투자는 크지만 장기적으로는 훨씬 경제적입니다.

🎨 이유 3: 우리 회사에 맞춘 커스터마이징

  • 회사 전문 용어 학습: 우리 회사 제품명, 부서 약어, 업무 프로세스를 미리 학습
  • 사내 문서 연결: 내부 위키, 업무 매뉴얼 등을 AI가 자동으로 참고
  • 정책 반영: 회사 규정에 맞게 AI의 응답 방식을 조정 가능
🎯 예시 외부 AI: "죄송하지만 귀사의 내부 프로세스는 모릅니다"
사내 AI: "출장 신청은 인사포털 → 전자결재 → [출장] 메뉴에서 하시면 됩니다!"

3. 🌐 Proxy 설정 이해하기

회사 네트워크는 보안을 위해 Proxy(중계) 서버를 통해 인터넷과 사내망을 연결합니다. Langflow가 외부 서비스에 접근하려면 Proxy 설정이 필요할 수 있습니다.

💡 Proxy란? 중계 서버를 의미합니다. 회사에서 인터넷을 사용할 때 직접 연결하지 않고, Proxy 서버를 거쳐서 연결됩니다. 마치 회사 정문의 경비실을 통과해야 외부로 나갈 수 있는 것과 비슷합니다.

🔧 언제 Proxy 설정이 필요한가?

상황 Proxy 설정 필요 여부
외부 AI 사용 (OpenAI) ✅ 필요 (인터넷 접근)
사내 AI만 사용 ❌ 불필요 (사내망만 사용)
Langflow 설치 시 ✅ 필요 (인터넷에서 다운로드)
집에서 작업 ❌ 불필요 (회사 Proxy 없음)

⚙️ Proxy 설정 방법

방법 1: 환경변수로 설정 (권장)

Python과 Langflow가 자동으로 Proxy를 사용하도록 설정합니다.

  1. 1IT팀에게 다음 정보를 요청합니다:
    • Proxy 서버 주소 (예: proxy.company.com)
    • Proxy 포트 번호 (예: 8080)
    • 인증 필요 여부 (ID/비밀번호)
  2. 2Windows에서 환경변수 설정:
    • Windows 키 누르고 "환경 변수" 검색
    • "시스템 환경 변수 편집" 클릭
    • "환경 변수" 버튼 클릭
    • "시스템 변수" 영역에서 "새로 만들기" 클릭
  3. 3다음 변수를 추가합니다:
    변수 이름 변수 값
    HTTP_PROXY http://proxy.company.com:8080
    HTTPS_PROXY http://proxy.company.com:8080

방법 2: pip 설치 시에만 Proxy 사용

Langflow를 설치할 때만 일시적으로 Proxy를 사용하는 방법입니다.

pip install langflow --proxy http://proxy.company.com:8080

방법 3: Langflow 실행 시 Proxy 제외 설정

사내 AI 주소는 Proxy를 거치지 않도록 설정할 수 있습니다.

  1. 환경변수에 NO_PROXY 추가
  2. 변수 값: localhost,127.0.0.1,internal-ai.company.com

Q: Part 4에서 쓴 FAISS는 로컬 파일에 저장되는데, 이것도 문제인가요?

⚠️ FAISS의 한계

FAISS는 내 PC에만 저장됩니다.
👉 다른 팀원이 사용할 수 없고, 서버에 배포할 수도 없습니다.

실무에서는: 사내 벡터 DB 서버(Pinecone, Weaviate, Milvus 등)에 저장해서

🎯 사내 RAG 구축 흐름 (간단 요약)

1. 민감 문서 준비 (예: 고객 계약서 100건) ↓ 2. 사내 서버에서 Text Splitter로 쪼개기 ↓ 3. 사내 Embedding 모델로 벡터화 ↓ 4. 사내 벡터 DB(Pinecone/Weaviate)에 저장 ↓ 5. 사용자 질문 → 사내 Retriever가 검색 ↓ 6. 사내 LLM이 답변 생성 ↓ 7. ✅ 모든 과정이 회사 내부에서만 처리!

Agent Builder는 회사가 자체적으로 운영하는 Langflow 클라우드 환경입니다. 사내 AI 모델과 사내 벡터 DB가 이미 연결되어 있어, 민감한 회사 데이터를 안전하게 다룰 수 있습니다.

구분 로컬 Langflow (학습용) Agent Builder (실무용)
설치 방법 내 PC에 Python + Langflow 설치 ✅ 설치 불필요 (웹 브라우저만 있으면 OK)
AI 모델 OpenAI (외부 서비스) ✅ 사내 AI 모델 (자동 연결됨)
벡터 DB FAISS (내 PC에만 저장) ✅ 사내 벡터 DB (팀 공유 가능)
데이터 보안 ⚠️ 외부로 전송 (OpenAI 서버) ✅ 회사 내부에서만 처리 (절대 외부 유출 없음)
사용 가능 문서 공개 문서만 (브로슈어, 공개 FAQ) ✅ 모든 문서 (계약서, 인사 정보, 재무 자료 포함)
협업 ❌ 개인 PC에서만 작업 ✅ 팀원과 프로젝트 공유 및 협업 가능
배포 ❌ 별도 서버 필요 ✅ 클릭 한 번으로 즉시 배포
비용 OpenAI 사용료 (토큰당 과금) ✅ 무료 (회사가 운영)
💡 언제 뭘 써야 할까?
  • 로컬 Langflow: 집에서 개인 연습, 새로운 기능 테스트, 공개 데이터 실험

✅ Python을 배웠다면: "아, 이 부분은 for문을 써야 하는데 잘못됐네. 고쳐보자!" (즉시 해결)

프로그래밍적 사고란? 복잡한 문제를 작은 단계로 쪼개서 논리적으로 해결하는 능력

👉 AI에게 명령할 때도:
• Python 모름: "파일 합쳐줘" (애매모호) → AI가 엉뚱한 결과물 생성
• Python 배움: "100개 CSV 파일을 반복문으로 읽어서, 'name' 컬럼만 추출 후 하나의 Excel로 저장해줘" (정확한 지시) → 완벽한 결과

✅ 가치 3: AI와의 협업 능력

AI 시대의 핵심 역량: AI를 "도구"처럼 사용하는 능력

비유:
• 운전을 모르는 사람 → 택시 기사에게 "그냥 어디론가 데려다줘요" (목적지 불명확)

🚧 Langflow의 5가지 한계

❗ 한계 1: 복잡한 조건문 처리 불가

예시: "고객이 VIP면 할인율 20%, 일반 고객이면 10%, 신규 고객이면 5% 적용"
Langflow: 복잡한 if-else 조건을 블록으로 표현하기 어려움
Python 코드: 10줄로 간단히 해결

❗ 한계 2: 반복 작업 자동화 제한

예시: "100개 고객 이메일을 각각 다른 내용으로 자동 발송"
Langflow: 반복 블록이 제한적, 대량 처리 어려움
Python 코드: for문 하나로 해결

❗ 한계 3: 외부 시스템 연동 어려움

예시: "회사 ERP 시스템에서 데이터 읽어서 자동 보고서 생성"
Langflow: 기본 제공 블록 외 커스텀 API 연동 복잡
Python 코드: requests 라이브러리로 간단히 연동

❗ 한계 4: 데이터 전처리 제약

예시: "엑셀 100개 파일에서 특정 조건 데이터만 추출 후 정리"
Langflow: 복잡한 데이터 처리 블록이 부족
Python 코드: pandas 라이브러리로 강력한 처리 가능

❗ 한계 5: 세밀한 제어 불가

예시: "AI 응답 속도를 최적화하거나, 메모리 사용량을 줄이고 싶다"
Langflow: 내부 동작 방식을 제어할 수 없음
Python 코드: 모든 파라미터를 직접 조정 가능

💡 Vibe 코딩(Vibe Coding)이란?

AI 코드 어시스턴트와 대화하듯이 코드를 작성하는 개발 방식

• 개발자가 "이런 기능 만들어줘"라고 자연어로 요청
• AI가 즉시 코드를 생성하거나 수정
• 개발자는 결과를 확인하고 피드백 ("여기 고쳐줘", "이 부분 추가해줘")
• AI가 다시 수정하는 대화형 개발 순환

👉 마치 옆에 천재 프로그래머가 앉아서 실시간으로 도와주는 느낌! 🚀

4. 코드 합치다가 문법 에러 (15분)

6. 결국 포기하고 IT팀에 요청 😭

소요 시간: 1시간 이상 + 실패

✨ Vibe 코딩 방식

나: "100개 이메일 주소를 읽어서 유효성 검사 후 엑셀로 저장하는 코드 만들어줘"

나: (실행) → 에러 발생!
나: "이 에러 고쳐줘" (에러 메시지 복사)

나: (실행) → 성공! ✅
나: "결과 파일에 날짜도 추가해줘"
AI: (1초 후) 추가 기능 반영

소요 시간: 5분 + 성공!

🤔 "그럼 코딩을 배울 필요가 없는 거 아닌가?"

아닙니다! 오히려 Python 기초를 배운 것이 더욱 빛을 발합니다.

❗ Python 기초 없이 Vibe 코딩을 시도하면?
  • ❌ AI가 만든 코드가 맞는지 틀린지 판단 불가
  • ❌ 에러 메시지를 봐도 무슨 문제인지 모름
  • ❌ AI에게 명확한 지시를 내리지 못함 ("뭔가 만들어줘")
  • ❌ 코드 수정이 필요할 때 어디를 고쳐야 하는지 몰라서 막막
✅ Python 기초를 배운 후 Vibe 코딩을 하면?
  • ✅ AI가 만든 코드를 읽고 이해할 수 있음
  • ✅ 에러가 나도 "아, 이 부분이 문제구나" 파악 가능
  • ✅ AI에게 정확한 요구사항을 전달 ("pandas로 읽어서 merge 해줘")
  • ✅ AI가 실수한 부분을 직접 수정하거나 재지시 가능

💡 비유: 운전과 네비게이션

Python 기초 = 운전 면허
Vibe 코딩 = 최신 네비게이션

• 운전을 배운 사람 → 네비게이션을 보고 효율적으로 목적지 도착
• 운전을 모르는 사람 → 네비게이션이 있어도 운전 불가

👉 Python 기초 없이 Vibe 코딩만 배우는 것은 운전 면허 없이 최신 자동차를 사는 격입니다!

그림 6-8. Visual Studio Code 메인 화면

🤔 VSCode가 뭔가요?

💡 Visual Studio Code란?

코드를 작성하고 실행하는 프로그램 (코드 에디터)

• 비유: 엑셀이 표 작업 도구라면, VSCode는 코딩 작업 도구
• Microsoft가 무료로 제공
• 전 세계 개발자들이 가장 많이 사용 (점유율 70% 이상)
• 가볍고 빠르며, 확장 기능(Extension)으로 무한 확장 가능

👉 Vibe 코딩에서 AI 어시스턴트가 작동하는 무대가 바로 VSCode입니다!

🎯 VSCode의 3가지 핵심 장점

✅ 장점 1: 무료이면서 강력함

• 완전 무료 (개인/기업 모두 사용 가능)
• Windows, Mac, Linux 모두 지원
• Python, JavaScript, Java 등 거의 모든 언어 지원
• 코드 자동완성, 디버깅, Git 연동 등 전문가급 기능 제공

✅ 장점 2: 확장 기능(Extension)으로 무한 확장

VSCode의 진짜 강점은 수만 개의 무료 확장 기능을 설치할 수 있다는 점입니다!

예시:
• Python Extension: Python 개발 환경 자동 구성
• Prettier: 코드 자동 정렬 (보기 좋게)
• GitHub Copilot: AI가 코드 자동 완성
• Cline: 사내 AI 어시스턴트 연동 (우리 회사 전용)

👉 마치 스마트폰에 앱을 설치하듯, 필요한 기능을 추가할 수 있습니다!

✅ 장점 3: AI 어시스턴트 통합 지원

VSCode는 AI 코드 어시스턴트와의 통합이 가장 뛰어난 에디터입니다.

• GitHub Copilot (외부 AI)
• Cursor AI (외부 AI, VSCode 기반)
• Cline (사내 AI, 우리 회사 전용)

👉 이 확장 기능들이 바로 Vibe 코딩의 핵심입니다!

부록: 용어 정리 및 Q&A

📖 필수 용어집

  • LLM (Large Language Model): 거대 언어 모델. 엄청난 양의 텍스트를 학습하여 사람처럼 글을 쓰고 이해하는 AI (예: GPT-4).
  • Prompt (프롬프트): AI에게 입력을 주는 명령어. 질문, 지시사항, 예시 등이 포함됩니다.
  • Token (토큰): AI가 글자를 처리하는 기본 단위. 대략 영어 단어 하나가 1.3 토큰, 한글 한 글자가 1~2 토큰 정도입니다.
  • Temperature (온도): AI의 창의성을 조절하는 설정값. 0에 가까우면 정해진 답만 하고, 1에 가까우면 창의적(가끔 엉뚱함)이 됩니다.
  • RAG (Retrieval-Augmented Generation): AI에게 문서를 참고 자료로 제공하여 답변의 정확도를 높이는 기술. "AI에게 참고서를 주는 것"과 같습니다.
  • Vector Store (벡터 저장소): 문서를 검색 가능한 형태(벡터)로 변환하여 저장하는 데이터베이스. FAISS, Pinecone, Weaviate 등이 있습니다.
  • FAISS: Facebook이 만든 로컬 벡터 검색 엔진. 내 PC에만 저장되며, 실습용으로 적합합니다.
  • Agent Builder: 우리 회사가 운영하는 Langflow 기반 클라우드 플랫폼. 사내 AI와 사내 벡터 DB가 연결되어 있어 민감 데이터를 안전하게 처리할 수 있습니다.
  • Embedding (임베딩): 텍스트를 숫자(벡터)로 변환하는 과정. 비슷한 의미의 단어는 비슷한 숫자로 표현되어 AI가 의미를 이해할 수 있게 합니다.
  • SSO (Single Sign-On): 하나의 계정으로 여러 시스템에 로그인하는 방식. Agent Builder는 회사 SSO 계정으로 접속합니다.

❓ 자주 묻는 질문 (Q&A)

Q. 코딩을 전혀 못해도 괜찮나요? A. 네! Langflow는 코딩 없이 마우스 클릭만으로 AI를 만들 수 있도록 설계되었습니다.
Q. 만든 AI를 스마트폰에서도 쓸 수 있나요? A. Agent Builder로 배포하면 스마트폰 브라우저에서도 접속 가능합니다! 공유 링크를 카카오톡으로 보내면 모바일에서도 사용할 수 있습니다.
Q. Agent Builder는 꼭 사무실에서만 접속 가능한가요? A. 회사 네트워크 정책에 따라 다릅니다. 일반적으로는 VPN을 통해 집에서도 접속 가능하니 IT팀에 문의하세요.
Q. 로컬 Langflow에서 연습한 내용을 Agent Builder에서도 똑같이 만들 수 있나요? A. 네! 로컬 Langflow에서 배운 방법(블록 배치, 연결, 프롬프트 작성)을 Agent Builder에서 그대로 사용하면 됩니다. 차이점은 OpenAI → Company LLM, FAISS → Company Vector Store로 블록만 바꾸면 됩니다!
Q. Agent Builder에서 처음부터 만들어야 하나요? A. 네, Agent Builder는 New Project로 처음부터 만드는 방식입니다! 하지만 걱정 마세요. 로컬 Langflow에서 연습한 흐름과 프롬프트를 그대로 복사해서 사용하면 5분 안에 똑같이 만들 수 있습니다. 😊
Q. Agent Builder 사용에 비용이 드나요? A. 회사가 운영하는 시스템이므로 직원은 무료로 사용할 수 있습니다! OpenAI처럼 토큰당 과금도 없습니다.
Q. 공개 문서(브로슈어)도 Agent Builder에서 써야 하나요? A. 꼭 그럴 필요는 없습니다. 개인 연습이나 공개 데이터는 로컬 Langflow를 써도 괜찮아요. 다만 팀과 공유하거나 배포할 계획이라면 Agent Builder를 권장합니다.
